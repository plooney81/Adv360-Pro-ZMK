# Adv360 Pro Keymap Reference

Quick reference for what each key does on each layer. Generated
from `config/adv360.keymap`. Update this file whenever the keymap
changes meaningfully.

## Physical layout overview

The Adv360 Pro has, per side:
- 6 columns x 4 rows of finger keys
- 1 outer column (4 keys: top row + 3 home-area)
- 1 row of bottom keys
- 6-key thumb cluster

Layer diagrams below use this approximate ASCII convention:

```
                        LEFT HALF                                                                       RIGHT HALF
+-------+-------+-------+-------+-------+-------+-------+                       +-------+-------+-------+-------+-------+-------+-------+
|  outer| col 1 | col 2 | col 3 | col 4 | col 5 |thumb 1|                       |thumb 1| col 5 | col 4 | col 3 | col 2 | col 1 | outer |
+-------+-------+-------+-------+-------+-------+-------+                       +-------+-------+-------+-------+-------+-------+-------+
```

`__` = transparent (`&trans`), `xx` = none (`&none`).

## MOUSE (layer 4) — reserved

Currently all `&trans`. Planned to mirror Planck Mouse layer:
- Wheel up/down on right hand top row
- Mouse buttons on right hand
- Acceleration controls on left hand (0/1/2)

Requires `CONFIG_ZMK_MOUSE=y` in `config/adv360.conf` before
this layer can do anything useful.
